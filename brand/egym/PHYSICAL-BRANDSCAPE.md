# eGym Lokhandwala — Physical Brandscape

> **The total re-theme.** Every physical surface and object in the building, zone by zone,
> walked in the order a member actually moves through the gym — street → door → desk → floor
> → iron → ring → cardio → lockers → washroom → out again. Nothing is left un-themed.
>
> House style = **Mighty-Mick's-of-Mumbai**: brick, hand-painted **canvas-red `#a4271f`**,
> **paper-cream `#fefae0`** lettering, **tobacco-black `#0e0a07`** ink, **brass `#b8862b`**
> plates, **leather `#b49676`** warmth, the raised **FIST**. Display type is **Alfa Slab One**
> (hammered, not typed); decals / IDs / numbers are **JetBrains Mono** uppercase at
> `0.25–0.4em` tracking; body is **Inter**. Every word is Robin's real word or pure iron-creed.
>
> **This document does NOT repeat the 18 wall posters** in `POSTERS-PLAN.md` (the manifesto
> wall, IRON IS RELIGION, 120→78, SHOW UP, THE FIVE, the wayfinding plates, the chalkboard,
> the homage, the wallpapers, etc.). Those are referenced where they hang, but this plan
> covers **every OTHER surface** — the doors, desks, machines, lockers, mirrors, floors,
> stairs, ropes, pipes, mats, signs, hooks and bins that the poster plan never touched.

## SYSTEM NOTE — materials & the naming rule

**Material vocabulary (one treatment family per surface-type, so the whole building reads as one hand):**

| Material code | What it is | Used on |
|---|---|---|
| **VINYL** | cut / printed adhesive vinyl decal (matte, weathered overlay) | glass, painted metal, smooth machine shrouds, consoles |
| **PAINT** | hand-painted (brush + stencil + overspray) directly on substrate | brick, concrete, plaster, raw walls, floors-as-art |
| **BRASS** | engraved / etched brass plate, screwed on hex bolts | wayfinding, ID plates, role plates, house-rule strips |
| **CANVAS** | hand-painted stretched/sagging canvas banner on rusty bolts | identity banners, section flags, overhead banners |
| **ETCH-GLASS** | etched / frosted-vinyl on glass (privacy + lettering) | entry doors, washroom doors, office glazing |
| **FLOOR** | epoxy-coat + floor-grade laminated vinyl inlay (anti-slip) | rubber floor zone graphics, walk-path creed, lane lines |
| **ACRYLIC** | laser-engraved / printed acrylic, stand-off mounted | directory map, price board, PR boards, notice frames |
| **ENAMEL** | baked / hard-enamel pictogram badge | washroom/door pictograms, fire & safety, fuel-station marks |
| **TAPE** | printed gaffer / hazard tape, sprayed stencil | re-rack lines, safety zones, plate-tree edges, threshold |
| **WOVEN** | woven jacquard / embroidered textile | towels, ring ropes wraps, bench cushions, mat-edge bind |

**THE NAMING RULE (carried from the poster plan, applied to objects):**

- **eGym-NAMED** — anything that is **identity, wayfinding, house-law, safety, or a transaction
  surface**: the street sign, entry doors, reception backwall, directory map, price board,
  section signs, the house-rules, the chalkboard, lockers header, washroom doors, exit. These
  carry the **eGym wordmark** (lowercase `e` in `mighty.red`, `Gym` in `paper-cream`,
  per `/brand/egym/logo/egym-wordmark.svg`) or a small `· eGym · LOKHANDWALA · ANDHERI W · MUMBAI ·`
  mono footer.
- **CREED-ONLY** — anything a member touches mid-effort or reads as a vow: machine ID decals,
  re-rack lines, mirror clings, riser lettering, plate stamps, the FIST seals, washroom
  one-liners. These stay **unbranded** (at most a whisper-small `· eGym ·` corner stud) so the
  iron reads as religion, not advertising.
- **NEVER** use **GYMROB** anywhere in the building — that is Robin's separate personal brand.
- One **ring-blue `#4687a6`** accent **per room, once** — reserved for THE RING zone; never spend
  it twice.
